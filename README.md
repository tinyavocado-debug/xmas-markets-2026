# 🛷 Sleigh Route: Ontario holiday markets 2026

An interactive map and timeline of the holiday markets listed by
[Destination Ontario](https://www.destinationontario.com/en-ca/articles/festive-holiday-markets-ontario).
See where they are, when they run (all season, a week or two, or just a weekend), and plan day trips.

- Pan or zoom the map to filter the timeline. Drag across the timeline to filter the map by date.
- Add markets to one or more days. Each day gets its own route and a Google Maps link.
- Your plan is saved in your browser, and the page URL shares it.

Static site, no build step. To run it locally: `python3 -m http.server 8767`, then open http://localhost:8767/.

Market details come from the Destination Ontario page (updated Nov 20, 2026). Map pins are placed by hand
and approximate, so check each market's own site before you go.
